Diccionario de Datos: Página Principal

Este documento contiene la descripción de las variables principales utilizadas en el portal administrativo del sistema de gestión de reuniones (Avance de Informe).

1. Entidad: Usuario (Sesión y Acceso)

Variable Tipo de Dato Descripción Ejemplo / Observación
email String Correo electrónico institucional del usuario. director@ugma.edu.ve
password String Clave de acceso al portal. (Cifrada en BD)
token String (JWT) Identificador temporal de la sesión activa. Generado tras login exitoso.

2. Entidad: Reunión (Agenda y Control)

Variable Tipo de Dato Descripción Ejemplo / Observación
title String Nombre o asunto central de la sesión. Consejo de Facultad - FACES
date Date Fecha programada para el encuentro. 2026-05-15
time String Hora de inicio de la reunión. 10:00 AM
location String Lugar físico o enlace a plataforma virtual. Auditorio Principal
description Text Puntos a tratar o agenda detallada. Revisión de presupuesto 2026
status Enum Estado actual de la reunión en el flujo. PENDIENTE, CONFIRMADA

3. Variables de Resumen (Estadísticas)

Variable Tipo de Dato Descripción Cálculo / Lógica
totalMeetings Integer Conteo total de reuniones programadas. Suma de reuniones del mes.
totalMinutes Integer Cantidad de actas generadas. Reuniones FINALIZADAS.

4. Relación: Invitados (Participación)

Variable Tipo de Dato Descripción Ejemplo / Observación
guestIds Array (UUID) Lista de identificadores de usuarios invitados. [id1, id2]
attendanceStatus Enum Respuesta del invitado a la reunión. ASISTIRÁ, RECHAZADA
Generado automáticamente para el Informe de Avance - Mayo 2026
